# Developer OS: Codebase Context

Developer OS is a frontend prototype for a developer workspace. It has dashboard, project, task-board, and GitHub views. This document describes the current code and data flow so contributors and coding agents can find the right owner for a change.

## Runtime Flow

```text
index.html (#root)
	-> src/main.jsx (imports global CSS; mounts React StrictMode)
		-> src/App.jsx (BrowserRouter and route table)
			-> /                         src/pages/Home.jsx
			-> /dashboard, /projects,
				 /tasks, /github,
				 /assistant                 AppLayout(active, children)
																			-> Sidebar(active)
																			-> TopNav
																			-> route page as children
```

`Sidebar.jsx` renders navigation links using its local `navItems` list. Each workspace URL must also have a matching route in `App.jsx`; `active` is passed into the sidebar to highlight the selected item. The home page is outside the workspace shell. The assistant route currently renders a placeholder defined inside `App.jsx`.

## File Ownership

```text
index.html                         HTML document and #root mount point
src/
	main.jsx                         React bootstrap; imports index.css and App
	App.jsx                          BrowserRouter route definitions
	index.css                        Tailwind import and global design tokens/base styles
	pages/
		Home.jsx                       Standalone home/marketing page
		Dashboard.jsx                  Dashboard UI and its local sample arrays
		Projects.jsx                   Project list UI and its local sample arrays
		Tasks.jsx                      Task board, sample tasks, task state and handlers
		Github.jsx                     Composes the GitHub feature sections
	components/
		layout/
			AppLayout.jsx                Shared workspace shell; renders Sidebar, TopNav, children
			Sidebar.jsx                  Workspace navigation and active-item styling
			Topnav.jsx                   Top bar presentation
			Background.jsx               Standalone background visual component
		github/
			GithubHeader.jsx             GitHub profile header/actions presentation
			GithubStats.jsx              GitHub summary statistics
			RepositorySection.jsx        Repository sample data; maps to RepositoryCard
			RepositoryCard.jsx           Renders one repository passed through repo prop
			PullRequestSection.jsx       Pull request sample data; maps to PullRequestCard
			PullRequestCard.jsx          Renders one pull request passed through pullRequest prop
			GithubActivity.jsx           GitHub activity sample data and activity list
```

Project-level files: `package.json` defines scripts/dependencies; `vite.config.js` configures Vite with React and Tailwind; `eslint.config.js` configures linting; `public/` holds static assets; `dist/` is generated by the production build and should not be edited as source.

## Page And State Flow

- Dashboard and Projects define their display data in arrays in the same page component that renders it. These pages do not currently consume shared project/task models.
- `Github.jsx` composes header, stats, repository, pull-request, and activity components. Repository and pull-request section components own their sample arrays and pass individual records to their card components through props.
- `Tasks.jsx` owns the task board state. `initialTasks` seeds Todo, In Progress, and Done columns; create-task and drag/drop handlers update React state with `setTasks`; the component re-renders from that state. State is in-memory and resets on reload.
- There is no API/service layer, network fetching, authentication flow, or persistent storage in the current frontend. GitHub data and most dashboard/project data are illustrative sample content. Search/filter controls and several action buttons are currently presentation-only; do not assume they are wired to data operations.

## Where To Make Changes

- Add or change a URL/page: update the route table in `src/App.jsx`.
- Add a workspace navigation item: update `navItems` in `src/components/layout/Sidebar.jsx` and add the corresponding route in `src/App.jsx`. Keep the `id` used for `active` consistent.
- Change shared workspace framing: edit `src/components/layout/AppLayout.jsx`, `Sidebar.jsx`, or `Topnav.jsx` according to ownership above.
- Change a page's layout or its current sample content: edit the matching file in `src/pages/`.
- Change GitHub section composition: edit `src/pages/Github.jsx`; change one section's data/list or one record's markup in its corresponding files under `src/components/github/`.
- Change task creation, movement, or board state: keep the state and handlers in `src/pages/Tasks.jsx` unless introducing a deliberate shared data layer.
- Change global CSS tokens or base element behavior: edit `src/index.css`. Most page-specific styling is expressed with Tailwind utility classes in JSX.

## Development Commands

```bash
npm install
npm run dev      # Start Vite development server
npm run build    # Generate the production site in dist/
npm run preview  # Serve the production build locally
npm run lint     # Run ESLint
```

The app uses React 19, React Router, Vite, and Tailwind CSS 4. No backend is required to run the current prototype.
